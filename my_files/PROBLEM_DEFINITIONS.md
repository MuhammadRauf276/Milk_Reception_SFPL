# Problem Definitions & Operational Flaws
1. **The 30-Minute Lab Bottleneck**: Holding vehicles at the testing block for full chemical (RM/MBRT) runs backs up the physical plant gate and security entrances.
2. **Data Leakage Risk**: Minor contractors can view competing procurement networks' prices, volumes, and reject logs, compromising supply chain boundaries.
3. **Accountability Gaps ("Zumeidaari")**: Uncontrolled edit behaviors allow manual metric tampering after data discrepancies are found between ZMCC parameters and plant receipts.
4. **Formula Errors**: Calculating complex dairy metrics manually via spreadsheet rows leads to math issues and broken values (e.g., `#REF!` errors shown in row data inputs).
